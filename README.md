# 🍾 Игристые классического метода — сайт

Статический сайт-гид по игристым винам классического метода и где их купить в Санкт-Петербурге. Построен на Jekyll + GitHub Pages.

## Что внутри

- **`index.md`** — главная страница с обзором и карточками 12 категорий.
- **`categories.md`** — полная сводная таблица.
- **`shops.md`** — 8 магазинов СПб со ссылками и адресами.
- **`glossary.md`** — 20 ключевых терминов.
- **`sources.md`** — источники и методология.
- **`assets/css/style.scss`** — кастомная винная палитра поверх темы Cayman.
- **`_layouts/default.html`** — шапка с навигацией и подвал.
- **`_config.yml`** — конфигурация Jekyll.

## Как опубликовать на GitHub Pages

### Вариант 1 — Самый быстрый (через сайт GitHub)

1. Зайди на [github.com](https://github.com), залогинься.
2. Нажми **«New repository»** (зелёная кнопка справа сверху).
3. Имя репозитория: например, `sparkling-wine-guide`. Сделай его **публичным** (Public). Не ставь галочку «Initialize with README».
4. На странице нового репозитория нажми **«uploading an existing file»**.
5. Перетащи в окно **все файлы и папки** этого проекта (`index.md`, `_config.yml`, папку `assets`, папку `_layouts` и т. д.). Подожди, пока загрузится.
6. Внизу нажми **«Commit changes»**.
7. Перейди в **Settings → Pages** (в левом меню).
8. В секции **«Build and deployment»**:
   - **Source:** Deploy from a branch.
   - **Branch:** `main` (или `master`), папка `/` (root).
9. Нажми **Save**. Подожди 1–2 минуты.
10. Сверху страницы Pages появится зелёный блок: **«Your site is live at `https://<твой-логин>.github.io/sparkling-wine-guide/`»**.

Готово! Сайт работает.

### Вариант 2 — Через командную строку (для тех, у кого установлен Git)

```bash
# В папке с этим проектом
git init
git add .
git commit -m "Initial commit: sparkling wine guide"
git branch -M main

# Замени <твой-логин> и <имя-репо>
git remote add origin https://github.com/<твой-логин>/<имя-репо>.git
git push -u origin main
```

Затем зайди в **Settings → Pages** репозитория и включи Pages по инструкции из шагов 7–9 первого варианта.

### Вариант 3 — Кастомный домен

Если хочешь привязать свой домен (типа `wines.example.com`):

1. Создай в корне репозитория файл `CNAME` с одной строкой — твой домен.
2. У регистратора домена добавь CNAME-запись, указывающую на `<твой-логин>.github.io`.
3. В Settings → Pages введи свой домен в поле «Custom domain».
4. Включи галочку «Enforce HTTPS» после того, как сертификат сгенерируется (5–15 мин).

## Локальный запуск (опционально)

Если хочешь править сайт локально перед публикацией:

```bash
# Установи Ruby (3.1+) и Bundler
gem install bundler

# В папке проекта
bundle install
bundle exec jekyll serve

# Сайт откроется на http://localhost:4000
```

## Как редактировать контент

Все основные страницы — это обычные **Markdown-файлы**. Их можно править:

- **Прямо на GitHub** — кликнуть по файлу, нажать карандашик, поправить, нажать «Commit changes». Сайт обновится через 1–2 минуты.
- **Локально** в любом редакторе (VS Code, Obsidian, Sublime).

### Как добавить новую страницу

1. Создай файл `новая-страница.md` в корне.
2. В начале файла должна быть «шапка» (frontmatter):

   ```markdown
   ---
   layout: default
   title: "Заголовок страницы"
   description: "Краткое описание для SEO"
   ---

   # Контент в Markdown
   ```

3. Чтобы добавить ссылку на эту страницу в навигацию — отредактируй `_layouts/default.html` и добавь новую `<a>` в блок `.site-nav-inner`.

### Как поправить стили

Все стили — в `assets/css/style.scss`. Цвета вынесены в CSS-переменные в начале файла:

```scss
:root {
  --wine-deep:  #6B2737;  /* основной винный */
  --wine-mid:   #8B3A4A;
  /* ... */
}
```

Поменяй переменную — и весь сайт перекрасится.

## Стек технологий

- **Jekyll** — генератор статических сайтов (нативно поддерживается GitHub Pages).
- **Тема Cayman** — встроенная тема GitHub Pages, переопределённая кастомным CSS.
- **Markdown** для контента.
- **Liquid** (шаблонизатор Jekyll) — в `_layouts/default.html`.

## Совместимость с Google Drive

Те же данные, что были в xlsx-таблице, — здесь раскрыты в виде сайта. Если хочешь вернуться к табличному виду:

- Все Markdown-таблицы корректно копипастятся в Google Sheets через **Файл → Импорт → Загрузить .md** (или через расширение Sheet Importer).
- Альтернативно — открой xlsx-файл через Drive (он рендерит таблицы как Google Sheets).
